# أبو العلا — Prototype 0.1

Prototype أولي للعبة رعب 3D مبنية على Godot 4.

## التشغيل
1. ثبّت Godot 4.x.
2. فك الضغط عن المشروع.
3. افتح `project.godot`.
4. شغّل المشروع.

## التحكم
- WASD: الحركة
- Mouse: النظر
- F: تشغيل/إطفاء الكشاف
- E: التفاعل

## الموجود حالياً
- لاعب FPS
- كشاف
- بداية زلزال بسيطة
- طابق أول
- أبو العلا يبدأ بالمطاردة بعد فترة
- نظام طوابق أولي

هذه نسخة Prototype وليست اللعبة النهائية. المرحلة التالية: بناء البناية والمصعد والأبواب والألغاز، ثم تصميم أبو العلا بشكل مرعب فعلياً.
